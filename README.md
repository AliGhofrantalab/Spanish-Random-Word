# 🇪🇸 Spanish Random Word

A simple and interactive JavaScript project that displays random Spanish words with their meanings and example sentences in Persian.

This project was built as a beginner-friendly exercise to practice HTML, CSS, and JavaScript fundamentals.

---

## 🚀 Live Demo
https://alighofrantalab.github.io/Spanish-Random-Word/

---

## ✨ Features

- 🎲 Random Spanish word generator
- 📖 Persian meaning for each word
- 💬 Example sentence in Spanish
- 🖱️ Simple button interaction
- 🎨 Clean and minimal UI design

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

---

## 📚 What I Learned

- Working with arrays and objects in JavaScript
- DOM manipulation
- Event handling (click events)
- Randomization using Math.random()
- Structuring a small front-end project
